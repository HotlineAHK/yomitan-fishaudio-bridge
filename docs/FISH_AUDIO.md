# Получение API-ключа Fish Audio / Getting a Fish Audio API key

## RU

1. Откройте <https://fish.audio/>.
2. Зарегистрируйтесь через Google или email.
3. Перейдите в <https://fish.audio/app/api-keys/>.
4. Нажмите **«Создать ключ API»**.
5. Дайте ключу имя, например `Yomitan`.
6. Скопируйте значение — оно начинается с `sk-fish-...`.
   **Ключ показывается только один раз.** Если закрыть страницу, придётся
   создать новый.
7. Вставьте ключ в поле «API-ключ Fish Audio» в приложении.

### Сколько это стоит

Fish Audio даёт небольшой стартовый кредит на бесплатном тарифе. Дальше
нужно пополнять баланс. Один запрос озвучки — это один символ текста,
списывается пропорционально. Кэш приложения сохраняет уже сгенерированные
фразы, так что повторные запросы не тратят кредит.

## EN

1. Open <https://fish.audio/>.
2. Sign up with Google or email.
3. Go to <https://fish.audio/app/api-keys/>.
4. Click **"Create API Key"**.
5. Name it, e.g. `Yomitan`.
6. Copy the value — it starts with `sk-fish-...`.
   **The key is shown only once.** If you close the page, you'll have to
   create a new one.
7. Paste the key into the "Fish Audio API key" field in the app.
